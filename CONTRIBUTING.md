# Contributing

Voivox repositories are public but not open source. Unsolicited pull requests are not accepted
until Voivox publishes a contributor license agreement or another explicit contribution policy.

Issues and discussions may be used for project coordination. Security reports must follow
`SECURITY.md`.

By sending feedback, issues, or pull requests, you represent that you have the right to share
that material and that it does not contain secrets, private user data, or third-party code you
cannot license.
